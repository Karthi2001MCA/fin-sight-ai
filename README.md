# FinSight AI

Intelligent Financial Data Assistant: upload transaction data and ask questions about your spending in natural language.

## Planned Features

- CSV transaction upload and storage (PostgreSQL)
- Financial analytics (totals, categories, top merchants)
- Natural language to SQL querying with safe SQL validation
- Document Q&A using RAG (LangChain + FAISS)
- Anomaly detection using Isolation Forest

## Tech Stack

Python, FastAPI, PostgreSQL, SQLAlchemy, Pandas, LangChain, FAISS, Scikit-learn, Docker, Pytest, GitHub Actions
